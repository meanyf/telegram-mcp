# Telegram MCP

Сбор сообщений выбранных Telegram-чатов, анализ в ChatGPT и доставка сводки
в личный диалог с Telegram-ботом.

```text
Telegram → сборщик Python → SQLite → MCP → ChatGPT → Telegram-бот
```

Сборщик работает через личный аккаунт Telegram. MCP передаёт ChatGPT ещё
не выданные сообщения за последние 24 часа. Правила анализа задаются в
`prompts/mcp_instructions.md`, расписание — в ChatGPT.

## Требования

- Linux x86_64 или arm64.
- Python 3.10+ с модулем `venv`.
- Telegram-аккаунт и ключи приложения `api_id` и `api_hash`.
- Аккаунт ngrok и authtoken для публичного подключения MCP.
- Telegram-бот для получения сводок.
- ChatGPT с возможностью подключения собственного MCP-сервера.

Для работы нужны включённый компьютер без сна и доступ к интернету.
Все команды выполняются из корня проекта.

## Установка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## Настройка Telegram

Получите `api_id` и `api_hash` в разделе **API development tools** на
[my.telegram.org](https://my.telegram.org). Порядок регистрации приложения
описан в [документации Telegram](https://core.telegram.org/api/obtaining_api_id).

```bash
.venv/bin/python -m telegram_mcp.telegram_collector setup
```

Введите ключи в терминале. Для входа откройте Telegram на телефоне:
**Настройки → Устройства → Подключить устройство** и отсканируйте QR.
Если включена двухэтапная проверка, введите её пароль в терминале.

QR также доступен в `.local/telegram/login-qr.svg`: его можно открыть в браузере.
При истечении срока QR обновляется, максимум три попытки. Файл удаляется
после завершения или остановки входа.

Выберите номера чатов через запятую. Повторный `setup` заменяет список
источников целиком: укажите все нужные чаты. Перед настройкой остановите сборщик.
Сессия сохраняется, поэтому повторный вход требуется при её отсутствии или отзыве.

## Настройка бота для сводок

Создайте бота через [@BotFather](https://t.me/BotFather) и получите его токен:
`/mybots` → выбрать бота → **API Token**. Откройте созданного бота с аккаунта,
на который хотите получать сводки, и нажмите **Start**.

```bash
.venv/bin/python -m telegram_mcp.telegram_bot setup
```

Введите токен скрытым вводом в терминале. Единственный найденный личный чат
выбирается автоматически; при нескольких чатах выберите свой из списка.
Получатель фиксируется локально, ИИ не задаёт адрес доставки.
Используйте бота без настроенного webhook.

Проверка отправки:

```bash
.venv/bin/python -m telegram_mcp.telegram_bot test
```

Команда отправляет тестовое сообщение в настроенный чат. Повторная отправка
того же теста пропускается, если его доставка уже подтверждена.

## Запуск

В первом терминале запустите сборщик:

```bash
.venv/bin/python -m telegram_mcp.telegram_collector run
```

Во втором терминале запустите MCP с туннелем ngrok:

```bash
python3 scripts/start_mcp.py
```

Скрипт подготовит `.venv`, установит зависимости и запросит authtoken со страницы
[ngrok](https://dashboard.ngrok.com/get-started/your-authtoken).
Токен вводится скрыто и не сохраняется в файлы. Его также можно задать
переменной окружения `NGROK_AUTHTOKEN`.

Сервер слушает `127.0.0.1:8765`. Скрипт выводит публичный **Server URL**
с окончанием `/mcp`. Оба процесса должны работать; остановка — **Ctrl+C**.
Остановка скрипта MCP закрывает туннель и завершает сервер.

## Подключение ChatGPT

1. Откройте **Plugins → «+» → Add custom MCP server**.
2. Укажите название `My PC Test`, URL из терминала и **Authentication: No authentication**.
3. Создайте и установите подключение, затем выберите его через `@`.
4. Для проверки попросите вызвать `hello_from_my_pc`.

MCP доступен без авторизации по публичному адресу, включая чтение выбранных
чатов и отправку сводки настроенному получателю.

Пример задания:

> Получи новые сообщения доступных чатов, составь выжимку по инструкциям
> сервера и отправь её через send_telegram_summary в мой личный чат с ботом.
> Разрешаю передачу этой сводки настроенному получателю.

Это задание можно использовать для расписания в ChatGPT. Если в задании
перечислены конкретные чаты, обрабатываются только они.

## Инструкции для анализа

Редактируйте `prompts/mcp_instructions.md`, чтобы задать темы, критерии полезности
и формат отчёта. Сервер читает файл при запуске и передаёт его ИИ как инструкции.
После изменения инструкций или инструментов перезапустите MCP и обновите
подключение в ChatGPT.

Промпт задаёт краткую выжимку, пропуск рекламы и повторов, ссылки на источники
и отправку готового отчёта в Telegram. Для каждого чата выполняется один запрос
за запуск. При отсутствии новых сообщений отправка в Telegram не выполняется.
Содержимое переписки рассматривается как данные для анализа.

## Сбор и выдача сообщений

Сборщик опрашивает Telegram раз в минуту. Начальная дата сбора — за сутки
до первого `setup`; она сохраняется в конфигурации и применяется также
к добавляемым источникам. Затем каждый чат собирается с последнего сохранённого
ID. После простоя сборщик догружает пропущенные сообщения. Запись сообщения
и отметки сбора выполняется одной транзакцией, без дублей при перезапуске.

Сохраняются текст, подписи к вложениям, время отправки, ID автора и ссылки
на сообщения каналов и супергрупп. Приватные ссылки доступны участникам источника.
Файлы, фото и голосовые не скачиваются; правки и удаления не синхронизируются.
База хранит собранную переписку без автоматической очистки.

При запросе MCP выбирает все ещё не переданные сообщения за последние 24 часа.
Период отсчитывается от времени запроса на компьютере и сравнивается со временем
отправки сообщения. Расчёт выполняется в UTC. Количество сообщений не ограничено.
Сообщения старше суток хранятся в базе, но не передаются ИИ, в том числе после
длительного простоя.

Отметка последнего переданного ID хранится отдельно для каждого чата
и сохраняется после перезапуска. Она общая для всех подключений и разговоров
ChatGPT, использующих этот сервер. Сообщения считаются переданными при вызове
инструмента, до анализа ИИ. При сбое ответа или анализа они не возвращаются
автоматически.

Длинная сводка отправляется частями как обычный текст; HTML и Markdown
не интерпретируются. Подтверждённые части записываются в журнал отправок.
Повтор идентичного текста тому же получателю через того же бота пропускает
подтверждённые части. При сетевом сбое после фактической отправки, но до ответа
Telegram API, возможен повтор части.

## Инструменты MCP

| Инструмент | Назначение |
| --- | --- |
| `hello_from_my_pc()` | Проверка подключения: приветствие, проверочный код и время UTC. |
| `list_telegram_chats()` | Выбранные чаты, количество сохранённых сообщений и время последнего сообщения. |
| `get_telegram_messages(chat_id)` | Ещё не переданные сообщения чата за последние 24 часа. |
| `send_telegram_summary(text)` | Отправка готового отчёта настроенному получателю. |

## Дополнительные команды

Один проход сбора:

```bash
.venv/bin/python -m telegram_mcp.telegram_collector run --once
```

Сбор с интервалом 120 секунд:

```bash
.venv/bin/python -m telegram_mcp.telegram_collector run --interval 120
```

Количество сохранённых сообщений по чатам:

```bash
.venv/bin/python -m telegram_mcp.telegram_collector status
```

MCP без туннеля:

```bash
.venv/bin/python -m telegram_mcp.mcp_server
```

## Структура и локальные данные

```text
telegram_mcp/         # сервер, сборщик, отправка ботом, работа с базой
scripts/              # запуск MCP с туннелем ngrok
prompts/              # инструкции для ИИ
tests/                # тесты
.local/telegram/      # локальные настройки, сессия и базы
```

В `.local/telegram/` хранятся:

| Файл | Содержимое |
| --- | --- |
| `config.json` | Ключи приложения Telegram, выбранные чаты и начальная дата сбора. |
| `account.session` | Сессия личного аккаунта Telegram. |
| `messages.sqlite3` | Сообщения и отметки сбора. |
| `delivery.sqlite3` | Отметки передачи сообщений ИИ. |
| `bot.json` | Токен бота и получатель сводки. |
| `bot-outbox.sqlite3` | Подтверждённые отправки частей сводки. |

Каталог `.local/` исключён из Git. Сессия и ключи дают доступ к аккаунту
и боту: вводите их локально и не публикуйте. MCP не возвращает их в результатах
инструментов.

## Тесты

```bash
.venv/bin/python -m unittest discover -s tests -v
```

Тесты проверяют хранение, восстановление сбора, отбор за последние сутки,
исключение повторов и отправку ботом. Внешние обращения Telegram в тестах
заменены заглушками, реальные сообщения не отправляются.
