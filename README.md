# Telegram: автоматический сбор

Сборщик читает только выбранные чаты личного аккаунта и сохраняет новые
сообщения в SQLite. Вход, выбор чатов и секреты остаются на компьютере.
Это первый этап: автоматический анализ и защищённый доступ к данным через MCP
ещё не подключены. Существующий тестовый MCP по-прежнему отдаёт только приветствие.

## Подготовка Telegram

Из каталога проекта:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python telegram_collect.py setup
```

Получите собственные `api_id` и `api_hash` в
[API development tools](https://my.telegram.org), как описано в
[инструкции Telegram](https://core.telegram.org/api/obtaining_api_id).
При setup введите их в терминале. Программа покажет QR-код для входа:
Telegram на телефоне → Настройки → Устройства → Подключить устройство.
Отсканируйте QR и при необходимости введите пароль двухэтапной проверки
в терминале. Номер телефона и код из сообщения не запрашиваются.
Если QR в терминале неудобно сканировать, откройте `.local/telegram/login-qr.svg`
в браузере. QR обновляется при истечении срока (до трёх попыток), файл удаляется
при завершении входа или остановке. Не присылайте QR в чат.
Затем выберите номера нужных чатов из списка.
Ключи приложения сохраняются до входа, чтобы не вводить их при каждом повторе.
Повторный setup меняет список; перед ним остановите сборщик.

## Сбор сообщений

```bash
.venv/bin/python telegram_collect.py run
```

Первоначально собираются сообщения с момента за сутки до первого setup,
далее — все новые. Опрос раз в минуту; интервал можно изменить через
`--interval 120`. После простоя сбор продолжается с последнего сохранённого
сообщения каждого чата. База и курсор записываются одной транзакцией,
повторный запуск не создаёт дублей. Ctrl+C останавливает сборщик.
Компьютер и процесс должны работать; запуск после перезагрузки пока ручной.

Разовый проход и проверка количества сохранённых сообщений:

```bash
.venv/bin/python telegram_collect.py run --once
.venv/bin/python telegram_collect.py status
```

Конфигурация, сессия Telegram и база хранятся в `.local/telegram/`, который
исключён из Git. Файл сессии даёт доступ к аккаунту — не отправляйте его или
api_hash в чат. При отзыве сессии в Telegram потребуется повторный setup.

Сохраняются текст, подписи к вложениям, время, автор и ссылки на сообщения
каналов/супергрупп. Для приватных источников ссылки открываются только у участников.
Файлы, фото и голосовые не скачиваются; правки и удаления старых сообщений
в этой версии не синхронизируются. Собранные данные пока остаются локально,
через публичный тестовый MCP они недоступны.

Проверка хранения и восстановления после сбоя (без подключения Telegram):

```bash
python3 -m unittest -v test_telegram_collect.py
```

# My PC Test

Тест подключения ChatGPT к компьютеру через MCP, без Google Drive и API-ключа OpenAI. Нужен бесплатный аккаунт ngrok.
Единственный инструмент `hello_from_my_pc` возвращает фразу
«Привет с моего компьютера!», случайный проверочный код и время UTC.

## Запуск

Нужны Linux (x86_64 или arm64) и Python 3.10+ с модулем `venv`.
Зарегистрируйтесь на https://dashboard.ngrok.com/signup и скопируйте authtoken
со страницы https://dashboard.ngrok.com/get-started/your-authtoken.
Вставляйте токен только в локальный терминал, не в чат.

Из каталога проекта выполните:

```bash
python3 start_pc_gpt_test.py
```

Скрипт создаст `.venv`, установит зависимости и попросит токен скрытым вводом.
Токен не сохраняется в файлы. Можно передать его через переменную окружения
`NGROK_AUTHTOKEN`, если она уже настроена.
Затем скрипт запустит сервер на `127.0.0.1:8765` и туннель через официальный
Python SDK ngrok. Отдельную программу ngrok устанавливать не нужно.
Оставьте терминал открытым. Ctrl+C закроет туннель и остановит сервер.

## Подключение в ChatGPT

1. Скопируйте строку `Server URL для ChatGPT` из вывода скрипта.
2. Откройте Plugins → «+» → Add custom MCP server.
3. Укажите название `My PC Test`, Server URL — скопированный URL (он уже содержит `/mcp`), Authentication — `No authentication`.
4. Установите подключение, выберите его через `@` и отправьте:
   «Вызови hello_from_my_pc».

Бесплатный ngrok выдаёт аккаунту постоянный dev-домен; при повторных запусках
с токеном того же аккаунта адрес сохраняется. Бесплатный тариф имеет лимиты:
https://ngrok.com/docs/pricing-limits/free-plan-limits.
Старое подключение Cloudflare нужно один раз заменить подключением ngrok.
Тестовый сервис доступен без авторизации по публичному адресу; используйте
его только для этой тестовой фразы. Реальные чаты hh.ru к нему не подключены.

Для запуска только локального сервера после установки зависимостей:

```bash
.venv/bin/python pc_gpt_test.py
```

Предыдущий контекст работы сохранён в `chat-hh-codex.json`.
